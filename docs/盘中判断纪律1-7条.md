盘中监控/分析时的判断纪律四条（2026-06-11 五粮液误判复盘产出，详见项目内 docs/盘中监控_20260611.md "13:50 误判复盘"节）：

1. **资金主体命题**（护盘资金/主力/北向"在买/在卖"）的合格证据等级 = 增持进展公告、龙虎榜、大宗交易记录；盘面价格走势只能生成假设，输出时必须标"未验证"。
2. **负面存在性命题**（"X 没有发生/缺席"）必须等全时间窗口数据；盘中只允许时态限定表述（如"上午尚未观察到"），禁止"确认今日XX"。
3. **个股异动叙事前先做横截面对照**（vs 组合内其他持仓/板块/大盘 ETF 同期涨跌与低点反弹幅度）；β 能解释的不给个股叙事。
4. **即兴观察项**（决策线之外临时加的判断）必须带显式判定标准——价位+穿越深度+持续时间——才可用"确认/触发"措辞；否则只记录价格事实。
5. **催化必须落日期**：归因/检索带回的"XX上市预期/政策在即/会议临近"类表述，必须追问精确日期并写入执行清单形成催化日历；盘前流程含一个前瞻动作——查"今天/本周持仓所属板块有什么排期事件"。教训：SpaceX 6/12挂牌日期6/5起即公开可查，6/10已写入决策#59却未落日期，导致6/12航天发展涨停（兑现日）盘前无预警；个股新闻管道（按symbol抓取）对板块级/海外日历事件结构性失明，必须靠检索补。横截面对照含板块维度，不只大盘ETF。
6. **结论血缘与变更声明**：战术层输出（盯线/简报）必须带长线结论锚（一句"上层决策#ID 不变"）；任何结论相对上次输出收紧/放松/反转时，必须显式声明"变更+触发证据"（如"新增PE数据导致收紧"）——没有变更声明，用户无法区分"新证据"与"判断摇摆"；估值数据（PE/PB/市值）是 EOD 决策的必要输入，缺失时决策必须标注"估值维度缺失"。教训：6/10 全组合无估值数据下完成9个决策（快照仅比亚迪填了valuation_basis），6/12 补拉PE/PB后措辞锐度突变（航天发展PB 8.1），被用户感知为"结论不一致"。

7. **题材归属与影子股主动映射**：①每只持仓核查必含"参股/影子股/题材归属"维度，像第2a红线一样**逐只必答**——即使结论是"无"，也要列出"已查其是否为某热点/拟IPO公司的影子股、是否参股、比例几何"，禁止"没说=没查"的静默漏报。②**"个股放量大涨却查无当日catalyst"= 影子股/题材炒作红旗，禁止当终点**；必须追问"是什么题材/影子股/资金主线在炒"，直到定位驱动或明确标注"已穷尽检索仍未定位"。③盘前/核查前先做一次"当下最热主线（机器人/宇树、算力、固态电池等）↔ 9只持仓"主动扫描，不依赖记忆里既有标签被动匹配。④已知题材锚固化在 `eod_watch_stocks.thesis` 的 `题材锚:` 行，核查前先 SELECT 过一遍。教训（2026-07-03 金发×宇树）：金发+5%放量，agent回"无当日catalyst"我当成了答案，漏掉"金发是宇树影子股(穿透持0.32-0.42%)、宇树7/2注册获批挂牌在即"这条常识级公开信息；合百×长鑫因记忆有标签查了、金发×宇树因无标签漏了——暴露"依赖既有标签被动匹配"的结构缺陷。见 [[keboda-lawsuit-false-alarm]] 同类"名称/主体核实"纪律。⑤**执行落点**：本条及"反软归因四闸"（软归因量级校验/红线对账/驱动类型锚/时点数值源）已固化为 docs/持仓分析工作流SOP.md 第2d节"每只必答核查输出模板"——散文规则会被时间压力跳过（2b早列"参股"仍漏金发），故检查须走"跳过就露馅"的固定产出 schema，别只靠记这条纪律。已证实的驱动类型/题材锚固化在 eod_watch_stocks.thesis 的 `驱动类型锚:` 行、红线台账在 main_risk（对账合并非重写），核查前先 SELECT 过一遍。

**Why:** 当日 10:18 用 48 分钟数据+无依据的 78 元心理位+0.09 元穿越深度"确认护盘缺席"，13:40 又用组合性反弹误归因"护盘出手"；两次同犯"用价格推断资金主体行为"的证据等级错误，且受前日红线股先验污染（确认偏误）。
