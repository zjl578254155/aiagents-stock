# 日内实时交易信号模块设计方案 v1

## Context

EOD 模块解决"持仓逻辑是否成立"（价值判断），但不解决"今天什么时候操作"（时机判断）。
本模块在 EOD 决策的基础上，利用 TDX 分钟级 K 线和实时报价，提供日内时机信号。

**设计原则**：EOD 决定做什么（HOLD/TRIM/WATCH/EXIT），日内模块决定什么时候做。
人工仍然决策，模块只给出"现在是好时机/坏时机"的信号。

---

## 模块边界

- **做**：针对持仓股，日内价格/量能异动提醒；结合 EOD 决策给出时机建议
- **不做**：全自动下单、非持仓股推荐、T0策略、A股以外品种
- **与EOD关系**：读取 EOD 最新决策作为上下文，不修改 EOD 任何数据

## 交易时段逻辑（A股规则）

| 时段 | 时间 | 行为 |
|---|---|---|
| 集合竞价观察 | 9:15–9:25 | 监控集合竞价价格，只输出 GAP 预告，不发操作推荐 |
| 开盘不稳定区 | 9:30–10:00 | 高波动，只发 HIGH urgency 信号 |
| 主要交易期 | 10:00–14:30 | 全部信号类型启用 |
| 尾盘窗口 | 14:30–14:55 | 加"今日最后机会"语义标记 |
| 集合竞价锁单 | 14:57–15:00 | 静默，不发信号（此时无法撤单） |
| 非交易时间 | 其余 | 轮询暂停，静默 |

## 五种信号类型

### 1. GAP（开盘跳空）

- 触发：开盘价 vs 昨收涨跌幅 ≥ +3% 或 ≤ -3%
- 时机：9:30 开盘时一次性触发
- 语义：隔夜出现重大变化

### 2. BREAKOUT（量价突破）

- 触发：当前价 = 今日新高 且 量比 ≥ 2
- 语义：主力进场，趋势加速确认

### 3. VWAP_DEV（分时均线偏离）

- 触发：当前价偏离 VWAP ≥ ±3%
- 计算：`VWAP = Σ(典型价 × 成交量) / Σ(成交量)`，典型价 = `(H+L+C)/3`
- 语义：价格偏离日内成本中枢，均值回归压力明显

### 4. PM_WEAK（午后转弱）

- 触发：13:30 后，价格由当日正涨幅转负
- 语义：午后无承接，今日偏弱

### 5. TAIL_SURGE（尾盘异动）

- 触发：14:30–14:55，量比突然 ≥ 3 且 5 分钟内涨跌幅 ≥ ±2%
- 语义：机构尾盘建仓或出货，方向明确

## EOD × 日内信号协作矩阵

| EOD 决策 | 日内信号 | 推荐 | 优先级 |
|---|---|---|---|
| HOLD | GAP_UP ≥ +5% | 高开溢价，考虑先减1/3止盈再观察 | MEDIUM |
| HOLD | 跌幅 ≤ -8%（任意信号） | 触发止损线，核实 EOD 持仓逻辑是否仍成立 | HIGH |
| TRIM | VWAP_DEV > +3%（价在均线上） | ✅ 此刻流动性最好，执行减仓 | HIGH |
| TRIM | BREAKOUT | ✅ 量价配合，减仓不会压价 | HIGH |
| TRIM | 跌幅 ≤ -2% | ⚠️ 弱势中减仓冲击成本高，等反弹窗口 | LOW |
| WATCH | PM_WEAK | ⚠️ 今日走弱，WATCH 升级候选，建议人工复核 | MEDIUM |
| WATCH | TAIL_SURGE（跌方向） | ⚠️ 尾盘抛售，建议明日重新评估 | HIGH |
| EXIT | 任何 | 📣 寻找当日最佳流动性窗口执行清仓 | HIGH |

## 量比客户端计算方式

```
5日均量 = eod_kline_cache 取最近5个交易日的 volume 均值
已过交易分钟数 = 上午已过(9:30起) + 下午已过(13:00起)，不含午休
交易日总分钟数 = 240（上午120 + 下午120）
当日已成交量 = /api/quote 的 TotalHand

量比 = TotalHand / (5日均量 × 已过分钟数 / 240)
```

## 数据结构（内存态，不新增数据库表）

```python
# 每次轮询更新，进程内持有
IntraState = {
    'code': str,
    'today_signals': list[IntraSignal],   # 当日已触发信号（append only）
    'vwap': float,
    'volume_ratio': float,
    'last_price': float,
    'change_pct': float,
    'last_update': str,                    # HH:MM:SS
}

IntraSignal = {
    'time': str,           # HH:MM
    'type': str,           # GAP/BREAKOUT/VWAP_DEV/PM_WEAK/TAIL_SURGE
    'price': float,
    'change_pct': float,   # vs 昨收
    'volume_ratio': float,
    'vwap_deviation': float,
    'eod_action': str,     # HOLD/TRIM/WATCH/EXIT（来自 eod_analysis_db）
    'recommendation': str,
    'urgency': str,        # HIGH/MEDIUM/LOW
    'reasoning': str,
}
```

**持久化**（可选）：每日 CSV `data/intraday_signals/YYYYMMDD.csv`，列与 IntraSignal 字段对应。
不建库，进程重启当日内容丢失（可接受：日内信号不需要跨天保留）。
